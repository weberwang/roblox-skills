## V2 模型生产规格

- 生产类别：待填写 `productionRoute`；先分流合格资源复用、规则几何原生构建和纯表面修改。新几何组件的具体生成模式与选择依据统一填写在下方“逐组件路由结果”表中。
- 冻结来源与还原要求：待填写 source image 的版本/状态/用途、目标 viewId、`decomposition.restoration` 中关联的要求 ID；相机、FOV、视口和锚点只有实测时写测量，未知值及原因明确保留。
- 受限替代（仅适用时）：待记录用户明确指定的外部路线，或 Roblox 能力缺口及已确定替代方案的来源；默认不启动外部制作。
- 来源与消费者：待填写 sourceRef、公共资源 ID/修订（复用时）、许可和消费节点；生产规格定位不能覆盖真实来源身份。
- 目标规格：待填写尺寸、轴向、Pivot、部件职责、碰撞、锚定、交互、材质/贴图、Rig/动画需求与 Streaming 假设。
- 调用计划：待填写工具、实际支持的参数、用户提示/参考图来源、分件和可调属性；不适用参数明确说明，不能编造通用图像入参。
- 候选与造型约束：待填写候选轮廓、比例、风格核对方式；工具是否能直接使用参考图及其真实入参；非等比缩放的必要性和造型/纹理尺度复查。文本生成只记为待审候选。
- 预算与验证：待填写网格/实例/纹理预算、实际测量方法、必要退出条件、可交接 V4 的验证及不支持的测量项。
- 写入与恢复：待填写临时产物与正式父级、共享影响、原位替换基线、单写者和失败恢复范围。
- 交付与退出：待填写直接展示的编号标注图来源、逐项依据、剩余问题和下一步；manual 或必要人工决定的真实确认另记现有阶段字段。

## V3 生成与接入事实

- 当前目标与源：待填写 Studio/Place/Universe、Edit 模式、源数据/同步方式及修改前基线。
- 代表性样板：先按 V2 `restoration.samplePlan` 组合最小且有代表性的内容，在目标 viewId 下检查比例、轮廓、材质尺度、接缝、遮挡、层次和风格。逐轮记录到现有 `stageReviews.production.sampleAttempts`，包含 id、当前 candidate/revision/viewId、组件和要求 ID、创建时间、当前视觉证据、检查结果及接受结果。
- 样板接受：绑定同一 `sampleId`（该轮尝试 id）、`candidate`、`revision`、`viewId` 和当前 `evidenceIds`，`scope: sample`，结果为 `NOT_RUN`/`PASS`/`FAIL`，并记录 `manual`/`automatic` 模式。人工确认引用用户对当前样板的真实消息；自动模式仅在明确授权后使用，并精确引用授权消息、sample 范围、sampleId、candidate、revision、viewId。旧候选、全局方向批准、生成成功、技术 PASS 或资源 ready 不构成接受。
- 扩展记录：批量生产或全场布局前，在 `stageReviews.production.expansions` 记录类型、sampleId、revision、candidate、startedAt 和范围，并引用开工前已经接受的最新样板。未接受前只修复和复验样板；已授权生成/上传仍有效，合格既有资源可复用。
- 调用与任务事实：待填写参数/结果文件、jobId（仅后台任务）、真实终态和新旧路径；未执行为 NOT_RUN，不凭任务受理宣称完成。
- 审查与装配：待填写实际产物、脚本/属性/依赖审查、材质配对、贴图替换或切分映射、正式父级及接线结果。
- 回读与登记：待填写 readback 证据 ID/路径、Console 增量、资源总表 ID/当前修订、实际 Asset ID 或实例路径、当前消费绑定；未就绪候选不提前登记 active。

### V4 交接范围

待填写运行加载、输入/交互、碰撞、生命周期、Streaming、动画和设备性能中适用的验证与所有者。生成和 Edit 技术结果不自动完成这些用例。

样板接受和全场视觉还原分别记录，不由数量、三角数、编译、布局、加载或资源 ready 推断。人工显示确认：NOT_RUN。当前候选、截图/检查要点及真实用户判断来源：待实际发生后填写。若用户指出明显差距，记录受影响视图/要求/组件并先修复最早失配层级；保留旧候选、FAIL 与复验来源，不改写历史结论。未经实际验证，不填写通过或虚构阶段时间、Asset ID、用户确认。
